4Install

Over USB, from this page

Works in Chrome or Edge. The U30 Pro only offers ADB over USB with the USB ADB module installed; flash it once in Magisk, then plug the device in and connect.


      

        Connecting doesn't work?
        
    
          
  • Only one program can use the device's USB ADB at a time. If adb runs on this computer, stop it first with adb kill-server.
    • 
          
  • The device must offer ADB on its USB port. Install the USB ADB module once; it keeps network and file transfer working and adds ADB next to them. Browsers can't reach network ADB such as 192.168.31.1:55555.
    • 
          
  • On devices that ask to trust this browser's key, accept it on the device, or connect again if it timed out.
    • 
          
  • Installing needs root: allow the shell's Magisk superuser request if the device asks.
    • 
        

      

      
Or by hand

      
    
        
  1. Copy the zip to the device.
    2. 
        
  2. In the Magisk app, open Modules, tap Install from storage and pick the zip.
    3. 
        
  3. Reboot the device.
    4. 
      

      

        Install with ADB

adb push u30p-boot-video-custom.zip /data/local/tmp/
adb shell su -c "magisk --install-module /data/local/tmp/u30p-boot-video-custom.zip"
adb reboot

      

      
This module replaces any installed boot video module. Magisk never updates it on its own, so your video stays until you install another one. If a boot does not complete, the module disables itself on the next boot and the stock animation comes back.
